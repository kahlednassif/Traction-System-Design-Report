# Traction-System-Design-Report
University project for Electric Drive Systems covering traction system design and component selection for a mid-size sedan

 Traction System Design: Mid-Size Sedan
 
 This project was completed for the EPES303-Electric Drive Systems course at Cairo University, Faculty of Engineering.  
 
 Project Overview
 
 This report presents the design and analysis of an advanced traction system for a mid-size sedan. We evaluated performance requirements, including motor selection (PMSM vs. BLDC) and energy storage solutions, to optimize efficiency and reliability.  
 
 Technical Specifications
 
 Vehicle Type: Mid-size sedan  
 Acceleration (0-100 km/hr) : ~7 seconds 
 Maximum Speed: 200 km/hr  
 Total Weight: 1850 kg  
 
 Conclusion
 
 The study concludes that the Permanent Magnet Synchronous Motor (PMSM), when paired with a Lithium-Ion battery, offers the most suitable combination for achieving superior performance, power density, and efficiency for this vehicle class.
